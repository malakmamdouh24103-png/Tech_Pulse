# TechPulse - Tech News Portal (PHP + MySQL + Bootstrap)

1. Copy this folder to C:\xampp\htdocs\
2. Start Apache + MySQL, import database.sql in phpMyAdmin (creates techpulse_db)
3. Site:  http://localhost/TechPulse/
4. Admin: http://localhost/TechPulse/admin/index.php   (admin / admin123)

Folders: config/ (database + helpers), layout/ (public header/footer), auth/ (login/logout),
admin/{includes,category,comments,posts}, uploads/ (post images), assets/css.
